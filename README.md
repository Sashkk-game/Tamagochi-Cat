                          Тамагочи "Котик"

Геймджем Учи.ру
Разработчик: Сашка
Дата: 22 апреля — 4 мая 2026

                            О игре

Это игра-тамагочи для детей 6-11 лет, где нужно заботиться о котике.
Чтобы покормить питомца, ребенок:
- Лепит из пластилина или рисует еду (яблоко, печеньку, банан и т.д.)
- Показывает поделку в камеру телефона
Чтобы поднять настроение питомцу:
- Нужно прыгать или приседать с телефоном в руке
- Или рассказать котику сказку
Если ничего не делать минуту, шкалы голода и счастья постепенно уменьшаются.
Родители могут посмотреть статистику: сколько раз ребенок кормил котика, делал зарядку и читал сказки.


                                     Идея и ценность

Проблема: Родители сталкиваются с трудностями контроля офлайн-досуга детей. Дети много времени проводят за экранами.
Решение: Игра объединяет экранное время с реальными действиями:
- Творчество — лепка из пластилина или рисование еды для питомца
- Физическая активность — прыжки и приседания для поднятия настроения котику
- Чтение — короткие сказки для развития речи
Почему это круто:
- Ребенок не просто сидит в телефоне, а двигается и творит руками
- Родитель видит конкретную пользу: сколько поделок сделано, сколько прыжков выполнено, сколько текстов(сказок) было прочитано
- Игровая мотивация стимулирует выполнять офлайн-задания


                                       Стек технологий

Движок: Unity 6
Платформа: WebGL
Языки: C#, JavaScript
Акселерометр: Input.acceleration
Камера: Web API (getUserMedia)
Хостинг: GitHub Pages


                                      Компоненты системы

Frontend (Unity + WebGL):
- Главная сцена — тамагочи с питомцем, шкалы голода и счастья
- Система кормления — генерация случайных заданий + вызов камеры
- Система активности — обработка акселерометра, счетчик прыжков
- Система чтения — отображение коротких сказок с кнопкой подтверждения
- Родительская панель — сбор и отображение статистики
Backend отсутствует — вся логика на стороне клиента.
Взаимодействие компонентов:
Кнопка Кормить - Выбор еды - Камера → Награда
Кнопка Активность - Акселерометр - Детект движений - Награда
Кнопка Почитать - Сказка - Кнопка Прочитал - Награда
Кнопка Родителям - Статистика - Отчет


                                     Как запустить игру

GitHub Pages
Ссылка: https://sashkk-game.github.io/Tamagochi-Cat/
Внимание: для работы камеры и акселерометра требуется HTTPS. При первом открытии браузер запросит разрешение на доступ к камере и датчикам — необходимо разрешить.
Так же хочется уточнить, что данная игра хорошо работает в телефонной версии браузера


                                    Как играть

Кормление (камера + поделки)
1. Нажать кнопку Кормить
2. Котик попросит еду (например, Хочу ЯБЛОКО)
3. Слепить эту еду из пластилина или нарисовать на бумаге
4. Нажать Открыть камеру и показать поделку
5. Нажать ГОТОВО - котик сыт, шкала голода увеличивается

Активность (акселерометр)
1. Нажать кнопку Активность
2. Появится задание: Сделай 5 прыжков или Сделай 5 приседаний
3. Выполнить движения с телефоном в руке
4. Акселерометр считает повторения (автоматически)
5. После выполнения шкала счастья повышается

Чтение (сказки)
1. Нажать кнопку Почитать
2. Появится короткая сказка про котика или его друзей
3. Прочитать сказку
4. Нажать Прочитано - котик радуется, шкала пополняется

Для родителей
Нажать кнопку Родителям, далее показывает:
- Время в игре
- Количество кормлений (поделок)
- Количество активностей (движений)
- Количество прочитанных сказок
- Какие навыки развивал ребенок


                              Известные ограничения

Камера требует HTTPS — требование браузера для безопасности
Акселерометр требует ручного разрешения — нужно нажать Разрешить в запросе браузера
Акселерометр в Unity 6 работает нестабильно — ограничение движка
На компьютере акселерометр не работает — нет датчиков движения
